## The Desktop App

Prefer a native app? The same emulator is packaged as an offline desktop application for Windows x64
and Linux with Tauri. Two installer variants are available:

| Variant | Ships | Notes |
|---|---|---|
| Minimal{.disk}  | rk0 (Unix V5), rk1 (RT-11), bootcode + the demo paper tapes (BASIC-11, ODT-11, ED-11, Lunar Lander) | ≈19 MB on Windows. The download is the application itself — artwork and audio — while the bundled images add about 1 MB. All other images are dragged & dropped at runtime. |
| Full{.disk}  | every image — RK/RL/RP/RA disks, TM tapes, all paper tapes | ≈103 MB on Windows, but all fifteen bootable images boot offline with zero extra steps. |

On Linux the installation size for every configuration may be substantially larger (it depends on the package format).
