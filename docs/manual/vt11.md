## The VT11 Vector Display (Display page)

An optional DEC VT11 vector-graphics display processor on its own green-phosphor CRT page (1024×768
logical resolution, auto-scaled to fit the window), enabled from the [CONFIG page](#config).
Lunar Lander uses it —
the [quick-boot wizard](#quick-start) enables the display and switches to the Display page
automatically.
