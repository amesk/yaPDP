## О проекте yaPDP

yaPDP — интерактивная среда высокой степени достоверности для
знакомства с вычислительной системой DEC PDP-11/70 и её программной
экосистемой. В отличие от простых эмуляторов процессора, yaPDP
воссоздаёт полный пользовательский опыт 1970-х годов: от переключения
битов на передней панели до загрузки Unix V5 на телетайпе.

Проект задуман как профессиональное хобби, демонстрирующее инженерную
культуру и внимание к историческим деталям. Он служит не только
инструментом для энтузиастов ретро-вычислений, но и платформой для
образования и цифрового сохранения.

### Ключевые возможности

- **Аутентичное оборудование:** Достоверное воспроизведение передней
  панели PDP-11/70, телетайпа Model 33 ASR, терминалов VT52/VT100,
  построчного принтера LP11 и векторного дисплея VT11.
- **Настоящее программное обеспечение:** В комплекте 16+ гостевых
  операционных систем, включая Unix V5, RT-11, RSTS/E, RSX-11M
  и BSD 2.11.
- **Публикуемые состояния:** Сохраняйте и передавайте полные состояния
  машины (память, устройства, содержимое экранов) через ссылки
  или GitHub Gist.
- **Готовность для музея:** Спроектирован для встраивания в
  образовательные сайты и цифровые экспозиции со сценариями
  guided restore.

### Для музеев и преподавателей

yaPDP создан для простой интеграции в музейные экспонаты,
образовательные платформы и личные блоги. Эмулятор работает в
браузере без сложной серверной настройки.

#### Встраивание эмулятора

Вы можете встроить yaPDP на любой сайт с помощью стандартного HTML
iframe. Посетители смогут взаимодействовать с живой PDP-11, не покидая
ваш сайт. Подробные инструкции и примеры — в разделе
[«Встраивание эмулятора»](#machine-state) главы об управлении
состоянием машины.

#### Создание интерактивных экспонатов

Используйте функцию **Share** для создания самодостаточных
экспонатов. Можно добавить собственные заголовки, описания, снимки
экрана и автоматические команды восстановления (например, запуск
конкретной программы).

Для надёжной загрузки у всех посетителей мы рекомендуем размещать
такие состояния на GitHub Gist. Это обходит ограничения CORS
(Cross-Origin Resource Sharing), которые часто блокируют прямую
загрузку файлов с внешних серверов.

#### Почему yaPDP подходит для образования?

- **Не требует установки:** Работает прямо в браузере.
- **Обучение с направляющими сценариями:** Используйте «Guided
  Restore», чтобы вести студентов по историческим рабочим процессам
  шаг за шагом.
- **Исторический контекст:** Включает подробную документацию
  о достоверности и ограничениях эмуляции, помогая отличить
  поведение эмулятора от характеристик оригинального оборудования.
