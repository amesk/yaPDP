# О чём этот проект

Цель - Разработка работающего web-эмулятора PDP-11/70 c аутентичной панелью управления и подключённым к консоли оператора телетайпом ASR 33.

# Компиляция проекта

Помни, что основной способ собрать что-то выполнить - запустить скрипт из-под MinGW bash, работающий в VSCode.
Чаще всего bash находится уже в нужном каталоге - дополнительно делать "cd ...." не требуется.
Все действия под генерации документации штатно производятся через Makefile.
